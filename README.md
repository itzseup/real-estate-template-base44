# Real Estate Template

A luxury real estate website template built with React, Vite, Tailwind CSS, and shadcn/ui components. Cloned from Base44.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

- `src/pages/` - Page components (Home, About, Properties, PropertyDetail, Contact, OurTeam, Blog, Accessibility)
- `src/components/` - Reusable components
  - `ui/` - shadcn/ui component library (44 components)
  - `home/` - Home page specific components
  - `about/` - About page specific components
  - `team/` - Team page specific components
  - `admin/` - Admin page components
- `src/lib/` - Utility functions and config
- `src/api/` - API client for Base44 backend
- `src/hooks/` - Custom React hooks

## Tech Stack

- React 18
- Vite 5
- Tailwind CSS 3
- shadcn/ui (new-york-v4 registry)
- Radix UI
- React Router DOM
- Framer Motion
- React Hook Form
- Recharts
- Cmdk (command menu)
- Embla Carousel
